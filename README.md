## Repo layout

```
.
├── index.html          # landing page linking to each project
├── README.md           # this file
├── Project0.html       # introduction page
└── Project1/
    ├── index.html
    ├── README.md       # full write-up + screenshots
    ├── css/
    ├── img/
    └── screenshots/
```

Each project folder is self-contained: it carries its own copy of any vendored library,
so an older project keeps working exactly as submitted no matter what later ones change.

## Running locally

No build step. Clone the repo and open any project's `index.html` in a browser.
